2. Scripts: Pre-request e Tests

❌ Insomnia

Settings → Script (centralizados)

✅ Bruno

Abas do request: "Pre-request" e "Test" (separadas)

3. Armazenamento: JSON vs .bru

❌ Insomnia

Tudo em JSON (arquivo único)

✅ Bruno

Arquivos .bru (um por request) - Git-friendly!

💡 Ganho: Diffs mais legíveis no Git, melhor para trabalho em equipe

Folders (uma hierarquia)

✅ Bruno

Folders + Collections + Workspaces (mais flexível)

Ambos suportam, mas em Bruno é mais eficiente:

💡 Importante: Sempre cache tokens STS antes de fazer requests. Economiza tempo e respeita rate limits.

📋 Snippet 1: STS Token com Cache

Onde usar: Pre-request do request "STS-Token"

const cachedToken = bru.getEnvVar('access_token'); const tokenExpiry = bru.getEnvVar('token_expiry'); const now = Date.now(); if (cachedToken && tokenExpiry && now < tokenExpiry) { console.log('✅ Token válido em cache'); bru.setNextRequest('Primeira-Chamada-Autenticada'); } else { console.log('🔄 Obtendo novo token...'); }

📋 Snippet 2: Armazenar Token + Expiração

Onde usar: Test (pós-resposta) do request "STS-Token"

const res = res.getBody(); const token = res.access_token; const expiresIn = res.expires_in || 3600; bru.setEnvVar('access_token', token); bru.setEnvVar('token_expiry', Date.now() + (expiresIn * 1000) - 60000); tests['Token OK'] = typeof token === 'string' && token.length > 0; tests['Status 200'] = res.getStatus() === 200;

📋 Snippet 3: Encadear Requests

Onde usar: Test (pós-resposta) para pular para próximo request

const body = res.getBody(); if (res.getStatus() === 200 && body.status === 'PENDENTE') { bru.setEnvVar('tributacao_id', body.id); bru.setNextRequest('Validar-Tributo'); } else { console.error('❌ Status inválido'); bru.runner.stopExecution(); }

📋 Snippet 4: Headers Padrão com Variáveis

Onde usar: Headers de qualquer request autenticado

Authorization: Bearer {{ access_token }} Content-Type: application/json X-Request-ID: {{ $randomUUID }} X-Timestamp: {{ $timestamp }} X-Client-Id: {{ sts_client_id }}

📋 Snippet 5: Assertions Rápidas

Onde usar: Test (pós-resposta) para validar respostas

tests['Status 200'] = res.getStatus() === 200; tests['Tem body'] = res.getBody() !== null; tests['Tempo < 1s'] = res.getResponseTime() < 1000; tests['Tem ID'] = res.getBody().id !== null; const body = res.getBody(); console.log('Response:', JSON.stringify(body, null, 2));

⌨️ Variáveis Dinâmicas (Ganhe Tempo!)

Use diretamente na URL, Body ou Headers:

Timestamp ISO {{ $isoTimestamp }}
Timestamp Unix {{ $timestamp }}
Hora atual (YYYY-MM-DD) {{ $date }}

🚀 Fluxo de Produtividade

1. Setup STS Token F5 ou Play
2. Usar Collection Runner Ctrl + Shift + E
3. Exportar como cURL Clique direito → Copy as cURL
4. Comparar respostas Aba Response → Compare

💡 Dicas de Ouro para Ganhar Tempo

1. Use Folder Variables: Configure timeouts, retry_max e base_path uma vez por pasta
2. Collection Runner: Execute múltiplos requests com dados diferentes (CSV/JSON)
3. Environment Switcher: Alterne entre dev/staging/prod com um clique
4. Duplicate Request: Crie variações rápido (Ctrl + D ou botão direito)
5. Pre-request Global: Coloque lógica comum para todos os requests

❌ "Token não está sendo usado"

Problema: Header Authorization está vazio

Solução: Verifique se:

  • 1. Executou o STS-Token primeiro (para popular access_token)
  • 2. Header usa {{ access_token }} (com chaves)
  • 3. Token não expirou (bru.getEnvVar('token_expiry') > agora)

❌ "bru is not defined"

Problema: Script não está na aba correta

Solução: O código do bru. DEVE estar em:

  • ✅ Aba Pre-request (antes do request)
  • ✅ Aba Test (após a resposta)
  • ❌ Em nenhum outro lugar

❌ "Request não encadeia para o próximo"

Problema: bru.setNextRequest() não funciona

Solução: Verifique:

  • 1. O nome da próxima request está exatamente igual (case-sensitive)
  • 2. Você está executando com Collection Runner (Play button)
  • 3. Não está com erro na resposta anterior

❌ "Salvo no Insomnia, mas não está em Bruno"

Problema: Collection não sincronizou

Solução:

  • 1. Exporte do Insomnia (Ctrl + Shift + E → Export)
  • 2. Abra Bruno e importe (File → Import)
  • 3. Ou: Delete a collection local e puxe do Git

❌ "Variáveis de pasta não aparecem"

Problema: Folder variables não são herdadas automaticamente

Solução: Em Bruno (v4.1+), use:

bru.getFolderVar('nome_variavel') // Ler bru.setFolderVar('nome_variavel', valor) // Escrever
