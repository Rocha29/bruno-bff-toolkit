Padrões Comuns

✨ Cache de Token

const cached = bru.getEnvVar('access_token') const expiry = bru.getEnvVar('token_expiry') if (cached && Date.now() < expiry) { bru.setNextRequest('Proxima') }

🔐 STS Token (Pre-request)

const token = bru.getEnvVar('access_token') const expiry = bru.getEnvVar('token_expiry') if (token && Date.now() < expiry) { console.log('Token em cache') bru.setNextRequest('Pular-STS') }
