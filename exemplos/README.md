# 📁 Exemplos de Collections

Collections prontas para usar como template. Copie e adapte para seu projeto.

---

## 📋 O Que Você Encontra

### 1. `.env.example`

Template com todas as variáveis que você pode precisar:

```bash
# Copie:
cp .env.example .env

# Edite com seus dados:
nano .env
```

### `colecao-bff-tributos/` (em breve)

Exemplo completo com:
- ✅ STS Token caching
- ✅ Fluxo encadeado: Consultar → Validar → Pagar
- ✅ Tests e assertions
- ✅ Folder variables
- ✅ Pre-request scripts

**Como usar:**
```bash
cd colecao-bff-tributos/
cp .env.example .env
# Edite .env com suas credenciais
# Abra em Bruno: File → Open Collection
```

## ✨ Quer Adicionar Sua Collection?

1. Crie uma pasta com nome descritivo: `colecao-seu-caso/`
2. Adicione `.env.example` como template
3. Crie README.md explicando a estrutura
4. Commite no Git
5. Abra PR!
